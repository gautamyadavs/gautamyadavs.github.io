The problem

A multiple-choice question can look polished while still giving away the answer, testing the wrong skill, or relying on implausible distractors. Reviewing those details consistently is part of producing a useful assessment.

I built MCQ Quality Coach to support generation and review against 19 item-writing flaw criteria, with instructions and reference material that connect question quality to learning objectives.

One problem, connected tools

The integrated repository also serves as a teaching artifact for extending AI assistants. It demonstrates three related approaches built around a shared validator:

  1. A skill packages the review instructions, rubric, and a validator script.
  2. An MCP server exposes validation and question-bank tools to an AI client.
  3. A multi-step workflow connects drafting, validation, review, and revision.

The shared validation core keeps the checks consistent across these paths. The workflow can call the validator directly or reach it through the MCP server.

Support judgment with specific checks

The tool combines explicit review instructions with deterministic checks. Its output gives an author a basis for revising an item; it does not replace checking subject-matter accuracy, alignment, or whether one answer is clearly best.

The code is available for inspection and adaptation, including the shared rubric and validation logic.

What this work demonstrates

This project connects assessment design with practical AI development. It turns a review rubric into a reusable authoring tool and makes the architecture itself available as an example learners can explore.
